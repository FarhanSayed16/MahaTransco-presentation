# **IAS AI Workshop — Complete Speaker Kit** 

## **IAS AI Workshop — Complete Speaker Kit** 

- **"AI as an Administrative Officer's Digital Assistant"** A 90-minute interactive session for senior IAS Group A officers. 

This kit is self-contained. Any presenter (or any AI) reading these files in order can reconstruct the full session, the slide deck, every live demo, and every answer to a tough question — without needing anything else. 

### **How to use this kit** 

1. Read PRESENTATION_ROADMAP.md first — the one-page mental model of the whole session. 

2. Read 01_MASTER_PRESENTATION.md — this is your speaker script. Rehearse from this. 

3. Build your slides from 02_PPT_CONTENT.md — one slide per section, nothing more. 

4. Before the session, run every prompt in 03_LIVE_DEMOS.md once, save the outputs as backup screenshots. 

5. Skim 04 – 11 in the days before the session — this is what makes you sound like an expert when officers push back or go off-script.

### **Non-negotiables for the day** 

Have every demo pre-run and screenshotted. Assume the venue Wi-Fi will fail at least once. 

- Never let a slide contain more than one idea. 

- Every AI concept is introduced **after** the audience has already seen it work, never before. 

- Close on the message: AI will not replace officers; officers who use AI well will outperform those who don't.
