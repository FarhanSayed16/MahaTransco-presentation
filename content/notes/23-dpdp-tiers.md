# DPDP Tiers

## Objective
Officers leave with a muscle memory: classify data → choose environment → never paste forbidden classes into free AI.

## Talking Points
- Open phone line metaphor for free/public tools.
- Habit: “Would I be comfortable if this exact text appeared on a public website tomorrow?”
- Walk the never-upload list slowly (Aadhaar, FIR, Cabinet, medical, tender eval, PII combos).
- Then run the card-sorting lab — Check answers.
- Bridge: “The answer isn’t no AI — it’s the right tier of AI.”

## Actions / Hotkeys
- Select card → click tier → Check answers → Reset if needed.
- Press `Space` to advance when finished.

---
*Suggested time allocation: ~4 minutes*
