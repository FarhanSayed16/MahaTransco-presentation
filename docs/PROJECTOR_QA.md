# Projector QA checklist

Run once before the workshop (1080p or venue projector):

- [ ] Opening title readable from back row
- [ ] Body text on Token Lab / DPDP readable
- [ ] Accent buttons visible (teal on light)
- [ ] Overview grid titles not cut off
- [ ] Live demo: Copy + Open ChatGPT works
- [ ] Scene 20: Copy script + Open HeyGen works
- [ ] Presenter panel (`P`) notes load
- [ ] Profile 90 hides optional scenes 10 & 19
- [ ] Fullscreen (`F`) works in Chrome/Edge

**Contrast target:** navy/ink on `#F5F7FA` / white — avoid dimming projector.
