# Deepfake Drill

## Objective
Six-step habit: PAUSE → SOURCE → INSPECT → SEARCH → VERIFY → ESCALATE.

## Talking Points
- Officers are targets and verification points.
- Use fictional examples only (e.g. “imagine a fake voice note from a District Magistrate”) — never name serving officials.
- Do not live-demo voice cloning or face-swap.
- Closing: same demos from Act III can be misused; defence is verification discipline, not avoiding AI.

## Actions / Hotkeys
- Click each step on screen.
- `Space` when finished.

---
*Suggested time allocation: ~4 minutes*
