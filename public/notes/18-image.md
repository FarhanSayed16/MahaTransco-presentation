# Instant Image

## Objective
Belief calibration: AI images can look real — useful for concepts, dangerous if trusted blindly.

## Talking Points
- Before opening the tool: “How many would trust this as a real photograph?” (if showing a pre-gen sample), or preview the prompt stakes.
- Generate / show relief-camp documentary style.
- First-draft campaign visual ≠ final government publication.
- No real official faces, no logos.
- Callback later in deepfake section: same capability, opposite intent.

## Actions / Hotkeys
- Open Gemini / Midjourney / ChatGPT Images.
- `Space` when finished.

---
*Suggested time allocation: ~5 minutes*
