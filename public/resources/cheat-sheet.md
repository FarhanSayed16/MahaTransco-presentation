# MahaTransco AI Workshop — One-Page Cheat Sheet

## Which tool for which job
| Job | Open |
|---|---|
| Draft / rewrite / multi-channel | ChatGPT or Claude |
| Draft + image in one place | Gemini |
| Research with links | Perplexity |
| Long public PDFs + citations | NotebookLM |
| Slides from a summary | Gamma |
| Image concepts | Gemini / Midjourney / ChatGPT Images |
| Short video / avatar | Runway / HeyGen (disclose) |
| Voice (approved scripts only) | ElevenLabs |

## Never upload to free / public AI
- Confidential / FOUO government files  
- Aadhaar or any citizen ID numbers  
- FIR content, investigation records, evidence  
- Cabinet / pre-decisional drafts  
- Unpublished financials or budgets  
- Medical records  
- Citizen name + address + phone + ID combinations  
- Tender evaluation / bid files before award  

**Habit:** *Would I be comfortable if this exact text appeared on a public website tomorrow?*  
If no → do not paste into a free tool. Use enterprise / on-prem / air-gapped by data tier.

## Data tiers (quick)
1. **Public** → consumer AI OK  
2. **Internal** → enterprise + no-training clause  
3. **Confidential** → local / on-prem SLM  
4. **Classified** → air-gapped only  

## Prompt template (reuse)
**Role · Context · Task · Audience · Tone · Length · Format · Avoid**  
Then iterate: translate → shorten → reformat for WhatsApp / social.

## Verify before you rely
- Numbers, dates, citations, legal sections → check a source or mark `[VERIFY]`  
- NotebookLM citations speed checks — they do not replace judgment  
- Synthetic media: label when required; never clone real officers without authority  

## Deepfake 6-step
**PAUSE → SOURCE → INSPECT → SEARCH → VERIFY → ESCALATE**

## Closing line
AI will not replace officers. Officers who understand AI will outperform officers who don't.
