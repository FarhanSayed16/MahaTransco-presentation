# Officer Operating System (OS) Playbook

A one-page daily discipline for MahaTransco / administrative officers using AI.

## 1. Choose the tool by the job
- **Draft / rewrite / multi-channel:** ChatGPT or Claude  
- **Draft + image:** Gemini  
- **Research with sources:** Perplexity  
- **Long public policy files:** NotebookLM / RAG — never paste confidential PDFs into consumer chat  
- **Image / video / voice:** Midjourney, HeyGen, Runway, ElevenLabs — then human approve + disclose when required

## 2. Choose the environment by data tier
| Tier | Examples | Environment |
|------|----------|-------------|
| 1 Public | Press notes, gazetted circulars | Consumer AI OK |
| 2 Internal | Drafts, memos | Enterprise AI + no-training clause |
| 3 Confidential | PII, tender evals, unpublished financials | On-prem / local SLM |
| 4 Classified | Cabinet / security | Air-gapped only |

## 3. Use the reusable template
**Role · Context · Task · Audience · Tone · Length · Format · Avoid**  
Then iterate: translate → shorten → reformat.

## 4. Prefer RAG for long files
Upload → retrieve → cite pages. Bigger context helps; retrieval still wins.

## 5. Verify before you publish
- No invented numbers, legal sections, or citizen names  
- Mark gaps as `[VERIFY]`  
- Label synthetically generated media (SGI) where required

## 6. Save what works
Reusable personas and a personal prompt library beat one-off magic asks.

**Habit:** Would I be comfortable if this exact text appeared on a public website tomorrow?

**Remember:** AI drafts. The officer remains accountable. IndiaAI: Do No Harm.
