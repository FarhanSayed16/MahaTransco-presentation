# Verification Checklist

Use before publishing any AI-assisted draft, image, voice, or video.

## Content
- [ ] Every number, date, and name exists in a source file or is marked `[VERIFY]`
- [ ] No invented legal sections, tariffs, or compensation amounts
- [ ] Jurisdiction is correct (TRANSco vs DISCOM vs district administration)
- [ ] Tone matches channel (circular / D.O. / citizen notice / press note)

## Data & privacy (DPDP practical)
- [ ] Data tier classified (1–4) before paste into any tool
- [ ] No Aadhaar, health, FIR, Cabinet, medical, or tender-evaluation content in consumer AI
- [ ] Personal names redacted unless already public and necessary
- [ ] Habit check: comfortable if this text appeared on a public website tomorrow?

## Synthetic media (SGI)
- [ ] AI presenter / voice / image is disclosed / labelled where required
- [ ] No real-officer face clones without explicit authority
- [ ] Script matches approved facts only

## Deepfake / viral forward SOP
1. **PAUSE** — do not forward under urgency pressure  
2. **SOURCE** — official channel?  
3. **INSPECT** — artifacts, lip-sync, audio; look for mandated labels  
4. **SEARCH** — official posts / reverse lookup  
5. **VERIFY** — confirm via control room / PIO / IT cell (second path)  
6. **ESCALATE** — report via proper channel; do not amplify first  

## Final gate
- [ ] A named officer has reviewed the draft
- [ ] Official channel of publication is approved
- [ ] After-action / file noting planned if operational

**Rule:** Fluent is not the same as true. Verify, then send.
