# Mahatransco Interactive AI Workshop Website

This project is a Next.js 15 App Router static site designed for a full-screen, keyboard-navigable interactive workshop presentation.

## Commands

- `pnpm dev` - Start the development server
- `pnpm build` - Build the static assets for production (creates static export if configured)
- `pnpm start` - Start the production server

## Directory Structure

- `content/` - All workshop text, prompts, demos, and lab content in JSON/MD.
- `components/` - Presentation shell, scenes, labs, playground, and presenter tools.
- `styles/` - Light-theme design system and CSS tokens.
- `public/backups/` - Offline backup media for demos.
